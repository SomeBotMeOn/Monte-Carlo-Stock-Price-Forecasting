# Численная дискретизация геометрического броуновского движения и качество медианного прогноза цен акций российского рынка в условиях санкционных шоков

Сравнение схем Эйлера–Маруямы и Милштейна для геометрического броуновского движения (GBM) на часовых данных Московской биржи методом Монте-Карло (100 000 сценариев на тикер, горизонт 24 часа). Обе схемы дают медианный прогноз цены → сигнал Long/Neutral/Short и портфельные риск-метрики (VaR, CVaR, Sortino, Profit Factor, Sharpe). Итог: сценарные риск-метрики у схем совпадают с точностью до сотых долей процента, различие проявляется только через пороговую классификацию одного пограничного тикера.

## Где что искать

| Путь | Содержимое |
|---|---|
| `Monte Carlo Forecasting.ipynb` | код: загрузка данных MOEX (ISS API), оценка μ/σ, симуляция схем Эйлера и Милштейна (Numba), метрики, портфели |
| `tickers.csv` | список тикеров MOEX |
| `results/<дата>/` | результат прогона: таблицы портфелей (`portfolio_table1/2.csv`), графики прогнозов по тикерам |

## Запуск

Зависимости: `numpy`, `pandas`, `matplotlib`, `numba`, `requests`. Открыть `Monte Carlo Forecasting.ipynb` в Jupyter и выполнить по порядку (конфигурация задаётся в первой ячейке кода).
